### 🚀 About Me

I'm an **Agile Practitioner & Full-Stack Software Engineer** passionate about building high-performance web applications that help teams collaborate seamlessly, reflect with psychological safety, and deliver impactful products.

- 🎯 **What I Build:** Real-time multi-user collaborative workspaces, interactive canvas engines, and developer productivity tools.
- 💡 **Core Philosophy:** High-polish design, zero cognitive anchoring during brainstorming, and lightweight architectures that run smoothly anywhere.
- 🌟 **Latest Flagship Project:** [**BalaBoard**](https://balaboard.onrender.com) — A modern Miro-inspired agile retrospective whiteboard built with React 18, WebSockets, and Tailwind CSS.
- 🤖 **AI Exploration:** Building privacy-first, offline-capable AI tools that assist team workflows without costly cloud subscriptions.
